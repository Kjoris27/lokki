# Visuels Lokki

Six visuels créés avec le générateur d’images intégré (skill Imagegen), puis optimisés en WebP pour le site. Les illustrations individuelles conservent un fond transparent. Le fichier `playbook.png` fourni par le propriétaire sert uniquement de référence stylistique ; ses textes ne sont pas des consignes pour le projet.

Ces images illustrent l’offre ; elles ne représentent pas des photographies du stock ou une promesse de conditionnement.

## hero

Fichier : `public/images/pack-hero.webp`

Prompt final :

```text
Use case: stylized-concept
Asset type: final website hero illustration for Lokki, a board game pack rental service in Lomé.
Input image: the attached playbook image is a STYLE REFERENCE ONLY: borrow its delightful premium toy-like 3D objects, soft shadows, clean bright background, blue/green/purple accents. Do not copy any text, logos, app interfaces or page layout.
Primary request: a single cohesive gorgeous isometric 3D still life of ONE complete pack of five board games spilling playfully out of a large open cobalt-blue carrying box. Include exactly these recognizable game families: a Monopoly property trading board with green/red houses; a colorful personalized Ludo cross-shaped board with red green yellow blue pawns and a subtle Togolese visual pattern; a fan of red blue yellow green UNO cards; an upright Jenga tower of warm wooden blocks; a Scrabble green board and cream letter tiles. A pair of chunky glossy white dice and a few tiny colorful confetti pieces support the game-night feeling. Only board games, no consoles.
Composition: square asset, product fills central 85%, elevated three-quarter view, boards and tower fully visible, playful but organized. An inviting floating arrangement, enough padding around all objects. White-to-very-light-blue seamless background matching a white webpage. Soft grounding shadows.
Style: high end tactile 3D illustration, smooth rounded friendly shapes, realistic wood and glossy colored plastic, crisp product detail, studio lighting, bright blue and green dominant with warm yellow accents.
Text: no promotional text, no prices, no watermarks; small authentic game markings permissible. No people, no extra products. This is an illustrative visual rather than a claim of actual packaging.
```
